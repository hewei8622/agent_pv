# 0014 — Shared investigation records and workflow replay

Date: 19 October 2026. Wei authorized implementation with “yes go ahead” after
reviewing the [v2 development plan](../planning/interactive-pv-prototype-v2.md)
and [workflow specification](../planning/workflow-visualization-v1.md).

## First implementation checkpoint

Implement the common public decision/context coordinator and a read-only replay
viewer of retained B1 evidence. Freeze the development experiment definition in
[investigation_experiment_v1.json](../../configs/investigation_experiment_v1.json)
before collecting any R/A comparison outcomes. That file defines task-specific
acceptance and a competent reference; adaptive implementation/configuration hashes
must still be frozen before comparison. It is not a benchmark result.

The shared coordinator must retain complete pre-action predictions and link them
to later observations, alongside information receipts and concise world/self
records. It serializes public inputs and validates references; it is a trusted
local data boundary, not a sandbox for hostile Python. Keep legacy contracts,
accepted recordings and runtime behavior unchanged.

The first recorded fixture checks this integrated data flow with actual numeric
MuJoCo/PV execution and authored external replies. It is a short integration
fixture, not an autonomous agent or live human/internet demonstration. Rendering
is explicitly disabled for this new fixture. The separate workflow viewer uses
retained, original rendered B1 images and recorded dynamics; it creates no new
sensor image and does not imply a newly executed graphics pilot.

## Workflow evidence

The viewer must show original camera observations, public availability, recorded
decisions and measured responses on one clock. An evaluator 3D reconstruction
may use private recorded geometry/pose and is visibly labelled. Public exports
must omit those payloads entirely. Public power is derived from valid matched
V/I readings; true power is separate evaluator evidence.

The viewer may orbit a recorded scene for explanation, but the agent did not
receive that view. B1 has no image interpretation or causal prediction; missing
records remain missing. A procedural replay establishes viewer correctness,
not adaptive performance. Original frames and source hashes must be preserved.

## Review and later work

Review this smallest integrated foundation before widening the cases or adding
memory, consistent with the approved plan. Actual adaptive decisions, matched
R/A evaluation and real human/web transports are subsequent deliverables with
their own evidence; model/provider configuration is not inferred from the coding
assistant. No paid call, external participant contact or new dependency is
needed for this checkpoint.

No old acceptance gate, rendered suite or original full pilot is rerun solely
to build the viewer. Run meaningful new non-render tests and relevant regression
checks, inspect the actual browser view/controls, and preserve any failures.
Hardware fidelity, full archived M3–M6, and open-ended autonomy remain outside
the claims of this checkpoint.
