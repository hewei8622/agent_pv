What this workflow establishes
Existing procedural capability
B1 captures two views, executes a bounded voltage probe, chooses the largest measured power among tested points, then obtains fresh V/I measurements. An operating point can be verified while its causal explanation remains unresolved.
Next comparison
An adaptive system must record evidence-dependent choices, information gaps and pre-action predictions using the same tools and resource limits. Paired executed runs are needed before claiming fewer experiments, useful external information or better PV operation.
Replay scope and source inventory
Offline, read-only replay. No network, controller, simulator or model is invoked. Evaluator exports contain private data and must not be supplied to a policy. The separate public export physically omits private truth and scene geometry.
